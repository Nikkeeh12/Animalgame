Branchit tehään seuraavast:



ainakun tehdään uutta kokonaisuutta esim. movement tai kamera tai arttikokonaisuuksia, niin tehdään uusi branch mihin nämä asiat pistetään. 

Esim. jos luon peliin liikkuvan kameran, niin sitten luon uuden branchin nimeltä liikkuva_kamera.



sitten jos halutaan lisätä näitä kokonaisuuksia yhteen, niin sitten luodaan taas uusi branchi ja lisätään ne halutut kokonaisuudet yhteen ja sitten poistetaan vanhat branchit koska miksi meillä olisi duplicateja

Esim. Jos haluan yhdistää liikkuvan kameran ja liikkuminen yhteen, niin meillä pitäisi olla valmiiksi branchit "liikkuva_kamera" sekä "liikkuminen". ekaksi luodaan uusi branch mihin yhistetään nämä halutut kokonaisuudet ja sitten poistetaan vanhat branchit
